This file is a template, not a real event. It has `draft: true` in its front
matter, so it appears while you run the site locally and is left out of the
published build.

## How to use it

1. Copy this file and give it a new name: the filename becomes the web address,
   so `geospatial-workshop-abuja.md` becomes `/news/geospatial-workshop-abuja/`.
2. Fill in the front matter above. `eventDate` is the day the event takes
   place; while that date is in the future, the item is lifted into the
   "Upcoming" strip at the top of the page.
3. Remove the `draft: true` line when the item is ready to publish.
4. Write the body here in Markdown: headings, lists, links and images.

Note that upcoming events are worked out when the site is built, so a rebuild
is what moves a finished event out of the upcoming strip.
